# Cherry Pong 🍨🍒

An ice-cream themed Pong game built with vanilla JavaScript and HTML5 Canvas!

## Features
- **Neapolitan Court**: Layered strawberry, vanilla, and chocolate background with floating sprinkles.
- **Sundae Dish Paddles**: Play with elegant glass sundae dishes loaded with scoops of ice cream.
- **Cherry Ball**: Realistic bouncing cherry complete with stem, leaf, shiny reflections, and particle trails.
- **Sound & Action**: Dynamic screen shake, combo multipliers, particle effects, and AI opponent.
- **Responsive**: Adapts smoothly to any window size with mouse and touch support.

## How to Play
- Move your mouse or touch the screen to slide your sundae dish paddle.
- Bounce the cherry past the AI's sundae dish to score points.
- Build combos without letting the cherry drop past your paddle!

## Run
Open `index.html` in any web browser — no dependencies or build steps required.
